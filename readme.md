## Project Overview

The Portfolio Website is a modern, responsive, and visually appealing personal portfolio developed using HTML, CSS, and JavaScript. The project is designed to showcase personal information, technical skills, projects, and contact details in a professional manner. The website features a glassmorphism-inspired design, animated skill bars, dynamic particle effects, and a responsive layout that works across different devices.

---

## Objectives

The primary objectives of this project are:

* To create a professional online portfolio.
* To showcase technical skills and projects.
* To demonstrate frontend development capabilities.
* To provide an interactive user experience through animations and visual effects.
* To improve responsive web design skills.

## JavaScript Functionalities

### Loader Animation

A loading screen appears while the website content is being prepared. Once the page loads completely, the loader automatically disappears.

### Animated Skill Bars

The progress bars begin at 0% width and animate to their specified percentage values when the page loads.

Examples:

* HTML → 75%
* CSS → 70%
* JavaScript → 60%
* UI Design → 50%

### Dynamic Particle Background

JavaScript dynamically creates multiple glowing particles that move across the screen, creating a futuristic visual effect.

Features:

* Random Particle Positions
* Continuous Animation
* Lightweight Performance

### Contact Form Validation

The contact form checks whether all fields are completed before displaying a success message.

Validation Rules:

* Name cannot be empty.
* Email cannot be empty.
* Message cannot be empty.
